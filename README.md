# Countdown Timer

A simple responsive countdown timer created using HTML5, CSS3, and JavaScript.

## Project Description

This project is a countdown timer that counts down to a specific target date. It displays the remaining time in days, hours, minutes, and seconds.

The timer updates automatically every second. When the countdown reaches zero, a completion message is displayed.

## Objective

The main objective of this project is to practice JavaScript Date objects, date calculations, setInterval(), DOM manipulation, and responsive web design.

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Features

- Live countdown timer
- Displays remaining days
- Displays remaining hours
- Displays remaining minutes
- Displays remaining seconds
- Automatically updates every second
- Configurable target date
- Countdown completion message
- Responsive design
- Mobile-friendly layout
